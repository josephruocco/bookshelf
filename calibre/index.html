WoodWork for Calibre

A fresh shelf from the books you already own.

Reshuffle your entire Calibre library—or any search or Virtual Library—into a browsable shortlist. Then connect WoodWork for iPhone to keep rediscovering it on your Home Screen.

Download the Calibre plugin Free beta · Calibre 7+ Get WoodWork for iPhone Available on TestFlight

The plugin works on its own. The iPhone app is optional.

Start with the whole library, a search, or a Virtual Library such as unread fiction.

Reshuffle

Surface a random shortlist of 24, 36, 60, or 90 books without changing metadata or files.

Take it with you

Connect the iPhone app to Calibre’s Content Server and display a rotating shelf as a widget.

Install the plugin

  1. Download WoodWorkShelf.zip above.
  2. In Calibre, open Preferences → Plugins → Load plugin from file.
  3. Select the ZIP, restart Calibre, then add Reshuffle Shelf under Preferences → Toolbars & menus.
  4. Use its menu to change shelf size or restore the view you had before.

Connect your iPhone

  1. In Calibre, choose Connect/share → Start Content Server.
  2. Keep the computer and iPhone on the same Wi-Fi network.
  3. In WoodWork, open Calibre Content Server and select the nearby server. Manual address entry remains available.
  4. Test the connection, choose a library if needed, and sync.

Local-first by design. The plugin contains no analytics and never changes Calibre metadata or ebook files. The iPhone app copies book metadata for the widget—not the ebook files themselves. For ordinary setup, keep the Content Server on your home network rather than exposing it to the internet.
