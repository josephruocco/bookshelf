WoodWork Bookshelf 1.0 · how to see the app's own-library features without a Mac or a Calibre server

On a fresh install WoodWork shows a public domain shelf so the widget is never empty. The app's actual purpose is to show the user's own library. This page provides a sample library so that flow can be reviewed on an iPhone alone.

1. Get the sample library onto the device

Open this page in Safari on the review device and tap:

Download sample library (48 books)

Safari saves it to Files → Downloads.

2. Import it

  1. Open WoodWork and tap Import a Library File…
  2. Choose WoodWork-sample-library.json from Downloads.
  3. The shelf replaces the public domain demo with the imported library.

3. What to look for

  1. Spine width follows page count. The Metamorphosis (96 pages) is a sliver; The Power Broker (1,246 pages) is the widest book on the shelf. Widths come from the page counts in the library file, not from a fixed set of spine graphics.
  2. Independent widgets. Add two or three WoodWork widgets to the Home Screen. Each draws a different rotating selection and can be given its own theme and layout from the app.
  3. On Your Shelf. The app lists exactly which books each widget is currently showing. For libraries that came from the Mac scanner or Calibre, tapping a book opens it in Apple Books, Kindle, or Calibre; the sample file has no reader links, so its rows are informational only.
  4. Demo toggle. Switching Demo books back on restores the public domain shelf; off returns to the imported library.

How real users get their library in

Two paths, neither of which involves a server of ours:

  1. Mac scanner (free download on the iOS page): reads the Apple Books and Kindle databases on the user's Mac, looks up page counts on Open Library, and publishes the shelf to the user's own iCloud container, where the iPhone app picks it up.
  2. Calibre Content Server: the app connects directly to the user's Calibre server on their local network and reads the library from it. See the Calibre page.

WoodWork is a single independently written Swift and SwiftUI codebase with no template, no third-party UI kit, no accounts, no analytics, and no network calls from the iPhone app except to a Calibre server the user enters themselves. Privacy policy: getwoodwork.app/privacy.
